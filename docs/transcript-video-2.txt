[02:38]
We apply the resulting weights to June's return. The code checks the date so that a later release doesn't make its way into the decision. If a rate pair is missing, the model keeps its existing holdings.

This model calculates the trade from weights that have already drifted with the market. The 25% annual turnover cap can limit the next trade. The net result deducts the modeled cost. We assume ten basis points for full one-way turnover, so a ten-point shift costs about one basis point of portfolio value.
