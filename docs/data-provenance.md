# Data provenance

**ETF closes.** The Yahoo Finance chart endpoint returned daily USD adjusted closes for BIL, IEF, LQD, and VT. The last dated valid daily observation within each calendar month was selected. All four symbols agreed on the last observed session for each of the 61 months from September 2021 through September 2026. The first price is the starting close for October 2021 returns. Dates in the price table label the month. The accompanying session table records the actual date. Returns across the refreshed and original Lab 15 files agreed to within 0.000075 percentage points in every fund-month. [Download URLs and retrieval record](../data/price_sources.json).

**FEDFUNDS.** Board of Governors monthly average of daily effective rates, reported in percent. For each return month, request an [ALFRED FEDFUNDS vintage](https://alfred.stlouisfed.org/series?seid=FEDFUNDS) as of the day before the prior month's last quoted session. All 60 cutoffs returned a valid effective vintage with the two required observation months. The compact archives preserve the dated source headers and the two values used by the rule. The parser rejects a future-dated vintage or an incomplete observation month and uses the vintage's observations rather than today's FRED history.

**Revision audit.** For each of the 60 primary vintages, compare the two values used by the rule, by measured month, with the November 23, 2026 [FRED current-series download](https://fred.stlouisfed.org/graph/fredgraph.csv?id=FEDFUNDS) archived in Lab 17. The [reference extract](../data/fedfunds-revision-reference.csv) contains the 63 distinct matched months. All 120 vintage observations matched their current-series values. This checks the values used by this rule against one later snapshot. The research run continues to use the dated vintages, which also protect against publication lag.

**Limitations.** The monthly close simulation assumes trades at the quoted close and does not model intraday drawdown, market impact, or full mandate suitability. The ETF adjusted closes reflect distributions and aggregate fund performance. The separate trading cost is a modeling assumption. Monthly timing and return labels are tested independently of strategy performance.
